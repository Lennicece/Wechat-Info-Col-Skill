# wechat-single-file-report

## When to use
- 用户要求“一个 Excel 完成交付”，且包含文章明细与内容提炼。
- 用户还没给具体关键词，希望先描述想了解的问题，再由模型自动补全关键词。
- 用户希望可配置抓取参数（篇数、阅读量下限、时间范围）。
- 用户要求筛选口径为“蓝标认证公众号或阅读量超过某阈值”。
- 用户希望固定中文 Sheet 名，便于直接对外流转。

## Steps
1. 先向用户收集 4 个输入参数（缺失时给默认值并明确告知）：
   - 想了解的问题或主题（自然语言）
   - 目标篇数（默认 50，上限建议 80）
   - 最低阅读量阈值（默认 500）
   - 时间范围（默认近20天，也支持近N天）
2. 基于“问题/主题”自动生成关键词：
   - 先抽取核心词，再扩展同义词、行业词、上下游词，形成 5-10 个关键词；
   - 关键词去重后写入检索参数（`SEED_KEYWORD + expand_keywords`）；
   - 若用户明确给了关键词，则以用户关键词优先。
3. 把用户输入映射到脚本参数：
   - `MAX_URLS = 目标篇数`
   - `READ_COUNT_THRESHOLD = 最低阅读量阈值`
   - `LOOKBACK_DAYS = 时间范围天数`
   - 主筛选条件：`is_blue_verified == True OR read_count > READ_COUNT_THRESHOLD`
4. 修改输出函数为单一 Excel：`微信公众号抓取_<关键词>_<YYYYMMDD>.xlsx`（同日同关键词重复运行追加 `HHMMSS`）。
   - Sheet 名固定为：
     - `抓取文章汇总`
     - `核心信息提取`
   - `抓取文章汇总`字段固定：`发布时间/发布人/发布标题/发布连接/阅读量`，按阅读量降序（同阅读量再按发布时间降序）。
   - `核心信息提取`输出逐篇 takeaways，建议列：`发布人/发布标题/阅读量/蓝标认证/takeaways/发布连接`。
5. 运行脚本并输出统计：成功数/失败数/符合条件样本数/输出文件路径。
6. 二次校验：读取产物确认 Sheet 名、字段、排序与筛选口径均符合用户参数。

## Pitfalls
- 不要跳过“参数询问”步骤，直接用默认值会导致结果偏离用户预期。
- 自动生成关键词时，必须保留用户原始主题词，避免只剩泛词导致召回失焦。
- 阅读量抓取受风控影响可能为空；筛选必须保留“蓝标认证”兜底，否则可能全量被过滤。
- 当用户给出很高阅读量门槛或很短时间窗导致样本为0时，应提示用户放宽阈值/时间并可一键重跑。
- Sheet 名必须严格使用 `抓取文章汇总` 与 `核心信息提取`，不要继续写 `Sheet1/Sheet2`。
- 命名规则必须包含关键词与日期，避免重复运行覆盖历史文件。

## Verification
- 运行前记录了用户输入参数：主题/篇数/阅读量阈值/时间范围。
- 文件命名符合：`微信公众号抓取_<关键词>_<YYYYMMDD>[ _HHMMSS].xlsx`
- 第一张表名为：`抓取文章汇总`，字段严格为：`发布时间 | 发布人 | 发布标题 | 发布连接 | 阅读量`
- `抓取文章汇总`已按阅读量降序排序（同阅读量再按发布时间降序）
- 第二张表名为：`核心信息提取`，包含逐篇 takeaways（至少包含 `takeaways` 列）
- 终端日志包含：抓取成功数、失败数、符合条件样本数、输出文件路径
