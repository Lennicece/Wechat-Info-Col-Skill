# 项目长期约定（微信公众号抓取交付）

- 交付物必须是单一 Excel 文件：`微信公众号抓取_关键词_YYYYMMDD.xlsx`（同日重复运行追加 `HHMMSS`）。
- 表1名称固定为 `抓取文章汇总`，字段：`发布时间 / 发布人 / 发布标题 / 发布连接 / 阅读量`，并按阅读量降序（同阅读量再按发布时间降序）。
- 主筛选口径：仅近20天文章，且满足 **蓝标认证公众号 或 阅读量 > 500**。
- 表2名称固定为 `核心信息提取`，必须给出逐篇文章内容总结（takeaways），建议包含：发布人/标题/阅读量/蓝标认证/takeaways/链接。
- 阅读量接口可能受风控影响为空，脚本需保留“蓝标”兜底筛选并在无样本时给出明确提示。
